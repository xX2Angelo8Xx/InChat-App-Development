# Project history

- 2026-09-22: initial game concept and first Android playtest build. Three puzzle mechanics, local daily ritual, free play, offline storage. Physical device feedback pending.
- 2026-09-23: first device review found the path and memory rounds too short, the sum feedback and hint weak, missing mode choice and performance feedback, and launcher/layout/audio icon roughness. Version 1.1 addresses those points. Second device review pending.
- 2026-09-23: second device review confirmed the visual and layout fixes, but found line puzzles still easy, reverse memory too abrupt, sum values crowded, and little visible level progression. Version 1.2 adds graded per-mode difficulty, daily escalation, a calmer sum readout, a more reachable two-star band, and a centered launcher symbol. Third device review pending.
