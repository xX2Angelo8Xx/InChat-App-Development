# Build and release

From `android/`: first decode the repository's **public, test-only** signing key with `base64 -d ../tooling/playtest.jks.b64 > playtest.jks`, then `gradle :app:assembleDebug :app:lintDebug`. A debug APK can be installed on a device with `adb install -r app/build/outputs/apk/debug/app-debug.apk`. The `loopline.yml` workflow runs generator checks, Android build, lint, signature inspection and artifact upload from a clean checkout. The playtest signing key is deliberately public and must never be used for a production release; it allows test APK updates to retain local progress. Package identity: `com.inchat.loopline`, version 1.0.0 (code 1), min API 26.

Device acceptance: launch without a network; complete all three daily puzzles; drag through several path cells in one gesture and backtrack; restart a memory round during playback; background/foreground; reopen to check progress; verify the next local calendar day has three new puzzles; play 10+ free stages. Device testing remains necessary after CI.
