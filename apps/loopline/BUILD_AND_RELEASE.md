# Build and release

From the Android directory: decode the repository's **public, test-only** signing key from tooling/playtest.jks.b64 into android/playtest.jks, then run Gradle assembleDebug and lintDebug. The CI workflow runs generator checks, Android build, lint, signature and package inspection, artifact upload and direct prerelease APK publication. The playtest key is deliberately public and must never be used for a production release; it lets 1.2.0 update earlier test builds while retaining local progress. Package identity: com.inchat.loopline, version 1.2.0 (code 4), min API 26.

Device acceptance: update an existing 1.1.1 installation without losing progress; check centered launcher icon; progress from short forward memory sequences to reverse at level 6; compare 4×4, 5×5 and 6×6 line puzzles; tap a sum tile and read its current row/column values; check only completed target chips turn green; verify a one- or two-error attempt awards two stars; open on a short screen and check whether every control remains visible; verify the next local calendar day has three new puzzles at the appropriate difficulty. Device testing remains necessary after CI.
