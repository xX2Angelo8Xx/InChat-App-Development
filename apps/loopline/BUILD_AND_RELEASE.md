# Build and release

From the Android directory: decode the repository's **public, test-only** signing key from tooling/playtest.jks.b64 into android/playtest.jks, then run Gradle assembleDebug and lintDebug. The CI workflow runs generator checks, Android build, lint, signature and package inspection, artifact upload and direct prerelease APK publication. The playtest key is deliberately public and must never be used for a production release; it lets 1.1.1 update 1.0.0 while retaining local progress. Package identity: com.inchat.loopline, version 1.1.1 (code 3), min API 26.

Device acceptance: update an existing 1.0.0 installation without losing progress; check launcher icon and mute/unmute glyphs; finish a 5×5 path by covering all free cells; swap two marked cells after a sum hint and observe row/column completion; play a reversed memory sequence; switch between three independent free modes; compare stars, time and personal best; open on a short screen and check whether every control remains visible; verify the next local calendar day has three new puzzles. Device testing remains necessary after CI.
