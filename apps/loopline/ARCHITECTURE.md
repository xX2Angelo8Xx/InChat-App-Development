# Architecture

One Android Activity hosts bundled HTML/CSS/JavaScript in a WebView. It requires no external runtime services. The puzzle generator uses a deterministic seeded pseudo random number generator. Daily seeds include the local calendar date, mode, stage and generator version; difficulty uses the count of completed daily rounds. Each free mode uses its own saved stage index. Path generation performs randomized depth first search for a self avoiding route on 4×4, 5×5 or 6×6, marks ordered anchors and blocks every cell outside the route. The player must cover every free cell. Sum generation derives six target sums from a valid permutation of 1–9 and scrambles it with a bounded number of swaps; any arrangement meeting all sums succeeds. Memory sequences start with three signals on 3×3, grow in length and area, then introduce shorter reverse sequences at level 6.

The only persisted state is `loopline-v1` in local storage: daily progress, per-mode free indices, stars, highest completed free stage and audio preference. Existing 1.0/1.1 progress is retained. Stars award 3 for a clean solution, 2 for one or two errors/hints/resets, and 1 for three or more. The time measurement starts with the first game interaction. Resetting app data removes progress. No JavaScript bridge is exposed. No network permission is requested.
