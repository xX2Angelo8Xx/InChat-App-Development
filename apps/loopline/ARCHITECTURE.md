# Architecture

One Android Activity hosts bundled HTML/CSS/JavaScript in a WebView. It requires no external runtime services. The puzzle generator uses a deterministic seeded pseudo random number generator. Daily seeds include the local calendar date, mode, stage and generator version; each free mode uses its own saved stage index. Path generation performs randomized depth first search for a self avoiding route, marks ordered anchors and blocks every cell outside the route. The player must cover every free cell. Sum generation derives six target sums from a valid permutation of 1–9 and scrambles it with a bounded number of swaps; any arrangement meeting all sums succeeds. Memory sequences are generated from the seed and reverse at higher levels.

The only persisted state is `loopline-v1` in local storage: daily progress, per-mode free indices, stars, personal bests and audio preference. Version 1.1 migrates the earlier aggregate free index into per-mode counters without resetting daily history. Resetting app data removes progress. No JavaScript bridge is exposed. No network permission is requested.
